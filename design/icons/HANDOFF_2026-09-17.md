## Hybrid delivery decision — authoritative

The final icon package is **hybrid SVG/PNG**.

- use simplified SVG where raster detail provides no visible advantage;
- use detailed, size-specific PNGs where authored material/lighting/texture is visibly superior;
- one canonical may use SVG at smaller sizes and PNG at larger sizes;
- PNG derivatives are reviewed/optimized per target size rather than accepted as a blind resize ladder;
- the SVG→PNG crossover is **not frozen**;
- no embedded-PNG-in-SVG wrapper is the default delivery strategy;
- `style_class` is a visual/review class, not a forced file format.

The current `tools/build-icons.py` scalable-only staging behavior remains a development scaffold. Do not upgrade the final package layout until the valid crossover experiment is complete.
