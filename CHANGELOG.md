# Changelog

All notable project changes will be documented in this file.

The project is currently pre-release. Until the first stable release, changes are collected under **Unreleased**.

## [Unreleased]

### Added

- Established the project as a complete Witcher 3 HyDE theme.
- Adopted a HyDE-compatible `Configs/` and `Source/` distribution structure.
- Added a dedicated development area for icon specifications and source artwork.
- Defined an initial target of 645 genuine icon designs before alias expansion.
- Added repository licensing and third-party asset tracking policy.

### Changed

- Expanded the project scope from an icon pack to a complete HyDE theme.

### Planned

- Validate canonical Linux, Freedesktop, KDE, HyDE, and application icon names.
- Expand icon aliases.
- Finalize the Witcher color system.
- Implement Hyprland, Waybar, Rofi, Kitty, Kvantum, and Hyprlock theme files.
- Build GTK, cursor, and Witcher icon packages.
- Add wallpapers and release screenshots.
- Add automated structure and asset validation.
